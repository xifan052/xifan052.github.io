js的事件循环 ⭐⭐⭐⭐⭐

1. 同步任务： 立即执行，先压入调用栈。 2. 异步任务： 被分为宏任务和微任务，分别放入各自的队列。 3. 微任务（Promises.then,Promise.catch,resove,reject,MutationObserver）： 会优先执行微任务队列中的所有任务。 4. 宏任务（setTimeout,setInterval,setImmediate,点击事件的回调,数据请求）： 微任务执行完毕后，事件循环才会执行宏任务队列中的任务。

  • PS:

    requestAnimationFrame不是同步任务，它的回调是异步执行的，它的任务类型独立于宏任务和微任务，与浏览器的渲染循环直接相关。

    点击事件本身并不是一个任务，而是一种触发任务的机制。

性能优化 ⭐⭐⭐⭐⭐

具体思路

性能指标 首次内容绘制（First Contentful Paint, FCP） 最大内容绘制（Largest Contentful Paint, LCP）

// 浏览器

// 获取 FCP
new PerformanceObserver((list) => {
    const entry = list.getEntriesByType['paint'](0);
    if (entry.name === 'first-contentful-paint') {
        console.log('FCP:', entry.startTime);
    }
    }).observe({ type: 'paint', buffered: true });

    // 获取 LCP
    new PerformanceObserver((list) => {
    const entry = list.getEntriesByType['largest-contentful-paint'](0);
    console.log('LCP:', entry.startTime);
}).observe({ type: 'largest-contentful-paint', buffered: true });


// 小程序
Page({
    onLoad() {
        this.startTime = performance.now();  // 页面加载开始时间
    },
    onReady() {
        const loadTime = performance.now() - this.startTime;  // 页面渲染完成的时间
        console.log('Page Load Time:', loadTime);
    }
});
